Constructors / Destructors

####
Difference between copy constructor and assignment operator

Copy constructor uses the contents of an existing object to create/initialize a new object. Whereas in assignment operator (=), we set the contents of an existing object to another existing object.

Copy constructor vs assignment operator:
```c++
#include <string>
#include <iostream>


class Student
{
public:
    // constructor
    Student(std::string name)
    {
        m_name = name;
    }

    // copy constructor
    Student(const Student& s)
    {
        m_name = s.m_name;
    }

    // Assignment operator
    // Except constructor and destructor, all other function members, including assignment operator, should return something.
    Student& operator=(const Student& s)
    {
        m_name = s.m_name;
        return *this; // this is a pointer to the object. ==> *this is the object!
    }

    std::string m_name;

};

int main(int argc, char* argv[])
{
    Student alice("Alice");
    Student ben = alice;

    std::cout << "alice.m_name = " << alice.m_name << std::endl; // Prints alice.m_name = Alice
    std::cout << "ben.m_name = " << ben.m_name << std::endl; // Prints ben.m_name = Alice

    Student jerry("Jerry");
    jerry = alice;
    std::cout << "jerry.m_name = " << jerry.m_name << std::endl; // Prints jerry.m_name = Alice

    return 0;
}
```
